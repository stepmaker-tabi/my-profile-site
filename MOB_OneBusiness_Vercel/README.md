# 원비즈니스 런칭 컨설팅·교육 제안서

빌드 없이 배포하는 정적 HTML 프로젝트입니다.

## Vercel 배포

### Git 저장소에서 배포
1. 압축을 풀고 `vercel.json`과 `dist` 폴더가 있는 프로젝트 루트의 파일을 Git 저장소에 올립니다.
2. Vercel에서 Add New → Project → 해당 Git 저장소를 선택합니다.
3. Framework Preset은 Other, Root Directory는 `vercel.json`이 있는 폴더로 지정합니다.
4. Build Command는 비워 두고 Output Directory는 `dist`로 지정한 뒤 Deploy를 누릅니다.

### Vercel CLI에서 배포
Vercel CLI가 설치된 환경에서, 압축을 푼 프로젝트 루트에서 `vercel --prod`를 실행하고 계정·프로젝트 연결 안내를 따릅니다.

## 구성과 편집
- `dist/index.html`: 모든 스타일·애니메이션·본문이 포함된 제안서. 다운로드 후 직접 열 수도 있습니다.
- `vercel.json`: 빌드 없이 dist 폴더를 배포하는 설정.
- 별도 패키지 설치·API 키·환경변수·서버가 필요하지 않습니다.
- Pretendard·Archivo는 외부 CDN에서 불러오며, 접속이 불가능하면 시스템 글꼴로 표시됩니다.
- 원문 12개 섹션, 계약 조건, 협의에 따른 조정 안내를 유지했습니다.

## 인터랙션
- 표지의 5개 코칭 영역: 클릭 또는 방향키로 상세 설명 전환.
- 스크롤 등장 효과, 현재 섹션 목차 표시, 읽기 진행 바.
- 요약 숫자 카운트와 노하우 적용 과정의 연결선 모션.
- 상단 모션 끄기 버튼과 OS의 모션 감소 설정 지원.
- 인쇄 / PDF 저장 시 표지와 본문을 인쇄용으로 표시합니다.

검색엔진 노출 방지 메타 태그를 포함합니다. 이는 접근 암호 기능이 아니며 배포 주소를 아는 사람은 열람할 수 있습니다.
